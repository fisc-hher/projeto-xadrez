# Projeto Xadrez

Projeto web estático com foco educacional sobre **o impacto das mulheres no xadrez**, destacando pioneiras históricas e a evolução da participação feminina no esporte.

## 📚 Sobre

A página apresenta um texto introdutório sobre nomes importantes da história do xadrez feminino, como:

- Vera Menchik
- Nona Gaprindashvili
- Maia Chiburdanidze
- Judit Polgár

Objetivo: valorizar a contribuição das mulheres no xadrez e incentivar o interesse pelo tema.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (inline no arquivo `index.html`)

## ▶️ Como executar localmente

Como é um projeto estático, basta abrir o arquivo HTML no navegador.

### Opção 1 — Abertura direta

1. Baixe/clone o repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.

### Opção 2 — Servidor local simples (recomendado)

No terminal, dentro da pasta do projeto, execute:

```bash
python3 -m http.server 8000
```

Depois, acesse:

- `http://localhost:8000`
